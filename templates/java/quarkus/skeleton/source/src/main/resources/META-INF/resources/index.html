Fruit Management API

This is a Fruit Management API built with Java 21 and Quarkus 3.33, providing RESTful interfaces for CRUD operations on fruits.

Delete this file once you start coding.

About the Implementation

The "Fruit" resources in this application serve as a comprehensive example demonstrating:

  • Contract-First API Development - OpenAPI specification driving interface generation
  • Domain-Driven Design - Separation between API models and Panache entities
  • CRUD Operations - Complete create, read, update, delete functionality
  • Data Persistence - Hibernate/Panache with PostgreSQL
  • Testing Strategy - Unit and integration tests with JUnit 5 and REST Assured

How to Model Your Application

Use this Fruit implementation as a template for your actual business functionality:

  1. Start with OpenAPI - Define your API contract in src/main/openapi/openapi.yaml
  2. Generate Interfaces - Run mvn package to create API interfaces
  3. Implement Business Logic - Follow the pattern in src/main/java/${{values.javaPackageName}}/${{values.componentId}}/api/impl/
  4. Create Domain Entities - Model your data in src/main/java/${{values.javaPackageName}}/${{values.componentId}}/domain/
  5. Add Tests - Follow the testing approach used for Fruit endpoints
